Projects

Development of a Testing System for Quality Inspection of Assembled EV Battery Packs

Developed a battery pack inspection system for electric vehicle production. The system communicates with the Battery Management System through CAN to verify individual cell conditions and support quality assurance after assembly.

Smart Control and Monitoring System for Street Lighting using Power Line Carrier Communication (PLCC)

Developed a smart street-lighting monitoring and control system using Power Line Carrier Communication (PLCC). A control unit installed on each streetlight sends operational data to a smart energy meter, which forwards it to the cloud for remote monitoring and control.

Dynamometer for Running and Braking Tests to Enhance Final Inspection in Electric Motorcycle Production

Developed a final inspection system for electric vehicles that performs running and braking tests, including speed and torque measurement. Test data is transmitted from the microcontroller to a PC through UART and displayed on a Node-RED dashboard for real-time monitoring.

Development of an EV Relay and Fuse Box Testing System for Quality Inspection

Developed an STM32-based relay and fuse box tester for electric vehicle production. The system automates continuity and functional testing to improve quality-control consistency and reduce manual inspection errors.

Design and Development of an IoT-Based Dimmable LED Driver for Energy-Efficient Lighting

Developed a 20 W smart LED driver with adjustable cool-white and warm-white lighting. The system integrates with Home Assistant for remote brightness control and automated scheduling.
